# Third-party assets

Everything in `assets/` is CC0 (public domain dedication). Nothing here is generated by an
image or 3D generation API - no Meshy, no Tripo, no diffusion model, no credits spent. Every
file below was downloaded from a free public source and converted locally.

### What was changed

1. **Container only.** The pack ships `.gltf` with the buffer inline as a base64 data URI.
   Each file was repacked into a binary `.glb` (JSON chunk + BIN chunk) with a short local
   Python script. No geometry, no rigs, no animations, no textures were altered - the byte
   content of the buffer is identical, it is simply no longer base64. This cuts about a third
   off the download.
2. **Materials at runtime.** The pack authors its materials with `KHR_materials_unlit`, which
   three.js resolves to `MeshBasicMaterial` - flat, ignores every light in the arena. At load
   time `js/arena3d.js` swaps each one for a `MeshStandardMaterial` that keeps the pack's own
   baked colour atlas as the albedo map. The texture data is untouched.

Both changes are inside what CC0 permits (it permits anything). They are documented because
"we modified the asset" is the sort of thing an asset audit wants stated explicitly.

Each mech carries the pack's animation set. The ones this project drives:
`Idle`, `Walk`, `Run`, `Punch`, `Kick`, `SwordSlash`, `HitRecieve_1`, `HitRecieve_2`,
`Death`, `No`, `Dance`.

## Weapons, arena, textures - built in code

Not third-party. The weapon rigs (drum, undercutter bar, flipper wedge, crusher jaw, hammer),
the octagonal cage, the floor plate texture, the spark sprite and the name plates are all
generated in `js/arena3d.js` at runtime. No free pack ships a BattleBots undercutter, and the
weapon is the one thing that has to match the scraped `weapon` field exactly.

## Fight data

`data/` is not in this folder. Bots and fights are read from `../battlebots-sim/data/`, which
was scraped from <https://battlebots.fandom.com> by the sibling project. See that project's
README for provenance and the source badge in its header.
